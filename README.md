# IPL Data Analysis

This project analyzes IPL cricket data using Python (Pandas & NumPy).

## 🔍 Key Questions

* Who are the top batsmen by runs?
* Who has the best strike rate?
* Who contributes most in winning matches?
* Who performs best in death overs?
* Who is the most complete batsman?

## 📊 Key Insights

* Virat Kohli emerges as the most complete batsman
* High strike rate does not always mean high impact
* Team strength influences performance metrics
* Death overs performance is critical for match outcomes

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook
